# Unity / UniVRM setup

1. Install a Unity version compatible with UniVRM 0.106.0 (check UniVRM release notes).
2. Create a Unity project and install UniVRM 0.106.0 from its official release/package.
3. Implement a browser-to-Unity file bridge for WebGL:
   - receive the selected .vrm bytes,
   - load with UniVRM's VRM 0.x importer,
   - export the loaded instance with the VRM 0.x exporter,
   - return generated bytes to JavaScript for download.
4. Build target: WebGL; test memory limits and large VRM files on Android.
5. Copy the WebGL build into `web/` and deploy Pages.

Do not assume a VRM 1.0 export path: this project targets VRM 0.x.
API names and exporter signatures must be checked against the exact UniVRM 0.106.0 package before compiling.
